# Tessellate compat mixins

- Config `wfcore-tessellate.mixins.json`: `required=false`, `defaultRequire=1` (injector miss => logged error, never fatal), `priority=2000`, package `com.norwood.wfcore.tessellate.mixin` (one sub-package per target mod).
- `TessellateMixinPlugin.shouldApplyMixin`: apply iff `tessellate` AND sub-package's target mod in `LoadingModList`. No Tessellate => zero mixins applied, `RegionThreads`/helpers never loaded.
- Mixin package prefix FORBIDS direct loading of any class under it => helpers live in `tessellate.<mod>` / `tessellate`, never under `tessellate.mixin`.
- Third-party compile deps: NONE. All targets `@Mixin(targets="fq.Name", remap=false)`; handler params = MC/NeoForge types, `Object` for third-party receivers (MixinExtras `WrapOperation`), `@Local` by MC type. `libs/compat/` not needed.
- Tessellate: `RegionThreads` = `LambdaMetafactory` links to `RegionTracker.index(ServerLevel)` + `LevelRegionIndex.leaseChunk(long)`; mismatch => `IllegalStateException`.
